# VERTEX ITSM

Enterprise IT Service Management and help desk platform, built as a single self-contained HTML file. Responsive across desktop, tablet and phone, with 8 color moods in dark and light.

**Live demo:** https://r3u-software.github.io/vertex-itsm/

Sign in with any persona on the login screen (IT Service Director, Service Desk Manager, L3 Technician, Employee). All data is simulated.

## What is inside

| Area | Pages |
|---|---|
| Command Center | Executive Dashboard, Analytics, AI Intelligence |
| Service Desk | Ticket List, Kanban Board (drag and drop), Technician Workspace, SLA Management |
| ITIL Practices | Incident, Problem, Change Management |
| Self-Service | Service Catalog, Employee Portal, Knowledge Base |
| Assets and Config | Asset Management, CMDB topology, Licences and Vendors |
| Operations | Monitoring, Automation, Communication, Integrations |
| Insight | Reports (Excel, PDF, CSV export) |
| Administration | User Management, Audit Logs, Admin Console, System Settings |

## Highlights

| Feature | Details |
|---|---|
| Command palette | Ctrl/Cmd + K, G-then-letter navigation, N for a new ticket, ? for shortcuts |
| Live SLA timers | Countdown clocks and breach states across ticket lists |
| Kanban | Real drag and drop between status columns |
| Visual maps | CMDB dependency map, floor map with device placement, ticket heat map |
| AI copilot | Summaries, reply drafts, root cause suggestions and forecasts |
| ITIL workflows | Major incident bridge, post-incident review, CAB approvals, change calendar |
| Multi-tenant | Tenant switcher for MSPs and white-label branding settings |
| Theming | 8 color moods (default Nebula), dark and light, density, motion and contrast options |

## Run locally

Open `index.html` in any modern browser. No build step and no dependencies other than Google Fonts.

## Notes

This is a front-end prototype with seeded demo data. Backend, authentication and integrations are represented as UI only.
